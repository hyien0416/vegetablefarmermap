# 合作社蔬菜農友互動地圖

## 操作方式
1. 開啟 `index.html`。
2. 地圖會顯示台灣 22 個縣市行政區，縣市名稱直接標在圖上。
3. 滑鼠移到縣市：浮出該縣市的農友、所在地與供應品項。
4. 點擊縣市：右側固定顯示該區農友清單。
5. 點擊農友：開啟農友詳細頁，最上方顯示供應品項，並預留照片、農友介紹、產地故事與文章連結。
6. 手機沒有 hover，可直接點縣市操作。
7. 上方可搜尋農友、鄉鎮與品項，亦可使用縣市下拉選單。

## 地圖圖資
前台使用 Taiwan Atlas `counties-10t.json` 縣市界圖（由內政部行政區界資料衍生），在瀏覽器載入後以 D3/TopoJSON 繪製。

## 更新方式
目前 `index.html` 內建一份農友資料作為保底資料。若未來將 Google Sheet「發布到網路」取得 CSV 網址，可把 `CONFIG.sheetCsvUrl` 填入公開 CSV 網址，前台即可優先載入 Sheet 的最新資料。


## 2026-10-02 地圖載入修正版
- 移除 D3 與 TopoJSON 外部程式庫依賴。
- 網頁開啟後先使用內建離線行政區互動圖，因此直接雙擊 `index.html` 也能使用。
- 若可連線至 Taiwan Atlas，網站會自動換成較精細的縣市行政界；若無法連線，內建地圖仍可正常操作。
- 滑鼠移到縣市顯示農友與品項；點縣市固定農友清單；點農友查看供應品項與介紹。

## 2026/10/02 介面更新
- 各縣市行政區改用不同色彩呈現。
- 滑鼠移到縣市時，農友浮動清單有固定最大高度。
- 農友較多時，可把滑鼠移入清單並使用滾輪向下瀏覽。
- 滑過縣市維持黃色提示，點選縣市維持橘色提示。
